# Alquila Ya

Plataforma de alquiler de propiedades tipo Airbnb, desarrollada en equipo como proyecto para el curso de Arquitectura de Aplicaciones Web (UPC).

## Funcionalidades

- Autenticación y autorización con JWT
- Control de acceso basado en roles (anfitrión / huésped)
- Búsqueda y filtrado de propiedades
- Sistema de reservas

## Mi rol en el proyecto

Responsable del desarrollo backend: diseño de la API REST, lógica de negocio y persistencia de datos.

## Tecnologías

- **Backend:** Java, Spring Boot, Spring Security (JWT)
- **Base de datos:** MySQL / PostgreSQL
- **Frontend:** Angular *(en integración)*

## Estado del proyecto

Backend funcional. Frontend desarrollado por el equipo, en proceso de integración al repositorio.
